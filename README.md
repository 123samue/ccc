# PHP Code Examples

A comprehensive collection of PHP code examples covering fundamental to advanced concepts.

## 📁 Files Included

- **index.php** - Main page with basic PHP syntax and examples
- **variables.php** - Variables, data types, constants, and type casting
- **arrays.php** - Indexed, associative, and multidimensional arrays
- **functions.php** - User-defined functions, closures, and arrow functions
- **oop.php** - Object-oriented programming (classes, inheritance, interfaces)
- **form.php** - Form handling with GET and POST methods
- **database.php** - MySQL/MySQLi and PDO database operations
- **style.css** - Styling for all pages

## 🚀 Getting Started

### Prerequisites

- PHP 7.4 or higher
- Web server (Apache, Nginx, or PHP built-in server)
- MySQL (optional, for database examples)

### Running the Project

#### Option 1: PHP Built-in Server (Recommended for testing)

```bash
php -S localhost:8000
```

Then open your browser and navigate to: `http://localhost:8000`

#### Option 2: Using Apache/Nginx

1. Copy all files to your web server's document root (e.g., `/var/www/html` or `htdocs`)
2. Access via: `http://localhost/index.php`
